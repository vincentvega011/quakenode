# Prior-art review for QuakeNode remediation

**Checked:** 2026-10-26  
**Scope:** closest work on real-time EEW evaluation, network faults, multistation replay, and the revised same-record preprocessing question. Focused review, not exhaustive systematic search.

## Decision summary

The broad claim of a unified causal replay/fault/fusion/warning-utility testbed is not defensible as novel. QCN directly studies EEW network congestion and link failures; CREW is an existing real-time EEW testing facility; Zuccolo et al. compare streaming EEW algorithms and target utility; EPIC Alaska provides progressive multistation real-waveform replay with association and catalog matching. Meier and ShakeAlert scenario work further establish target warning utility and production-system scenario testing.

The only candidate gap identified here is much narrower: paired measurement of whether the INSTANCE full-window processed product changes one fixed detector's P-relative results compared with causal processing of the same original waveform. No reviewed source in this focused check reports that exact comparison. This does not establish novelty: online/offline seismic preprocessing studies and relevant source artifacts have not been exhaustively checked. An adapter or proof that future samples can affect a full-window detrend is a software/data-integrity finding, not by itself an EEW performance contribution.

## Candidate contribution and falsifiable demonstration

**Candidate claim to investigate, not to publish yet:** on a fixed, legally accessible subset of reviewed-P HNZ traces, replacing the full-window INSTANCE count product with a declared causal input path changes (or does not materially change) one fixed STA/LTA detector's P-relative latency/miss result.

The experiment would require the same original miniSEED record matched to released HDF5; same P pick, time map, detector settings, scoring window, clean-stream schedule and optional identical fault mask; an incremental causal arm and offline product comparator explicitly labelled noncausal; per-trace outcomes/misses and uncertainty over independent events; and full-path counterfactual tests plus checksummed manifests.

It is meaningful only if the processing difference has a stable, interpretable consequence for a detector result or establishes a boundary for using the release product in incremental evaluation. If the effect is negligible with informative uncertainty, report that scoped bound. If dominated by arbitrary filter initialization or records cannot be matched, stop. No system-wide EEW or network-reliability conclusion follows.

## Verified facts versus leads

**Source-verified in this pass:** QCN publisher abstract confirms EEW network congestion/failure simulation and delay/lost-message outcomes; EPOS CREW page describes live SeedLink, isolated software VMs, QuakeML outputs and performance criteria; Zuccolo's primary paper describes streaming playback, two algorithms and target utility; EPIC article describes progressive real-waveform replay and event matching; INSTANCE paper describes trace preprocessing and reviewed-P selection.

**Carried forward/incomplete:** Meier and ShakeAlert details rely on prior audit and were not freshly retrieved. QCN public source code/reproduction package was not exhaustively searched. EPIC test-suite DOI is cited by the paper but archive terms/rerun steps were not checked. No exhaustive search covered identical-record causal/offline preprocessing comparisons or online detrending studies.

## Conclusion

No broad QuakeNode novelty claim survives. The same-record preprocessing comparison is a candidate distinction only; feasibility depends on raw record matching, network-specific data terms, exact timing, an independently chosen causal path, passing tests, and targeted prior-art review. Continue evidence gathering, not main-pipeline implementation.
